## <flipping-tile>
A web component that represents an interactive tile that can be flipped, reset, or hidden, in my case used in a memory game but could be used in similar interactive experiences.

## Attributes
This component does not currently have any attributes.

## Events
tile-clicked - The tile is clicked by the user.

# Example
<flipping-tile></flipping-tile>

# Result
A fully functional flipping-tile component that is used for every tile in the memory game.
