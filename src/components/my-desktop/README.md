# my-desktop Web Component
A web component that simulates a desktop environment, providing functionality to open and manage multiple application windows dynamically.

# Attributes
The <my-desktop> component does not use any custom attributes. Its behavior and functionality are managed internally.

# Events
Event Name	Fired When
window-clicked	A window on the desktop is clicked, bringing it to the front.
app-clicked A app icon is clicked and opens an instance of that app

# Example
<my-desktop></my-desktop>

# Result
A fully interactive desktop environment with app icons to launch applications. Users can in this case:
Open a "Memory Game."
Open a "Chat Application."
Open a "Tic-Tac-Toe" game.
Drag and bring windows to the front dynamically.
