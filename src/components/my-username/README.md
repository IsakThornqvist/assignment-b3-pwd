# my-username Web Component
A web component that handles username input and submission. It provides a customizable user experience for storing and retrieving usernames using local storage.

# Attributes
The <my-username> component does not currently support any custom attributes. However, its functionality can be extended by modifying the component logic.

# Events
Event Name	Fired When
username-submitted	A valid username is submitted via the input field or button.


# Example
<my-username></my-username>

# Result
A component that allows you to save your username in localstorage.
