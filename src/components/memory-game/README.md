# memory-game Web Component
A custom element that represents a memory game. The component provides a memory tile game where users flip tiles to match pairs, track time, and show the final score.

# Attributes
The <memory-game> component does not use custom attributes. Its behavior is controlled by the interactions with the game board and the timer.

# Events
Event Name	Fired When
window-closed	When the window is closed or the game is reset.
tile-clicked	When a tile is clicked during the game.

# Example
<memory-game></memory-game>

# Result
A fully funtional memory game that has 3 game modes and display a time and a score at the end of the memeory.
