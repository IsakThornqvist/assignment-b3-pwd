# Tic Tac Toe Web Component
A web component that represents an interactive Tic Tac Toe game. This component allows two players to take turns, detects winners or draws, and provides a restart feature.

## Attributes
The <tic-tac-toe> component does not use any custom attributes. It is ready to use as-is and manages its state internally.

# Events
Event Name	Fired When
restartGame When you click the restart button
handleBoxClick When you click a box in the tic-tac-toe grid


# Example
<tic-tac-toe></tic-tac-toe>

# Result
A fully interactive Tic Tac Toe game with a 3x3 grid where players can click boxes to play.
