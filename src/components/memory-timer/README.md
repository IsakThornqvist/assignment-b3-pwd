# memory-timer Web Component
A custom element that represents a memory game timer with features such as starting, stopping, resetting, and updating the score and time.

# Attributes
The <memory-timer> component does not use custom attributes. Its behavior and functionality are controlled through methods and events.

# Events
Event Name	Fired When
timer-started	When the timer is started.
timer-reset	When the timer is reset.
timer-ended	When the timer is stopped.

# Example

<memory-timer></memory-timer>

# Result
A timer component that can be used in the memory game to track how much time you are taking to finish the memory aswell as displaying a score.
